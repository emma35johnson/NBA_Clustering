# NBA_Clustering

Here is a project I completed with a collegue at the University of Minnesota-Duluth on the clustering of NBA players and teams. For this project, you'll find the data from GitHub user @NocturneBear in my forked repo: Data-NBA-2010-2014. In this repository, I have provided R code I wrote to perform the analysis with Model-Based Clustering. I have also provided the final written report, as well as a copy of our slides from the colloquium presentation we had to communicate our results.
