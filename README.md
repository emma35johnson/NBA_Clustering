# NBA_Clustering

Here is a project I completed with a collegue at the University of Minnesota-Duluth on the clustering of NBA players and teams.

For this project, you'll find the data from GitHub user @NocturneBear in my forked repo: Data-NBA-2010-2014.

In this repository, I have provided R code I wrote to perform the analysis with Model-Based Clustering (see "all clean NBA.R" and "NBA Notebook.Rmd"). 

Under main, I also have 2 branches dedicated to the final written report and a copy of our slides from the colloquium presentation where we communicated our results to peers and faculty.
